# Landing Demo

Open `#/landing-demo` after choosing a site and UTC date in the planning workspace. The HUD uses returned JPL Horizons samples for the selected coordinates and date. Use the sample selector to inspect a different returned UTC time. The LOLA card shows a matching provisional Site04 sample where supported, or a coarse LDEM_4 point elevation where the bundled cutout covers the location.

The replay, altitude above the demo surface, vertical speed, lander path and terrain art are illustrative. The altitude and speed readouts use the same easing model. Thirty seconds of playback represents sixty simulated seconds. Start, pause, resume or scrub the replay, or jump directly to a phase from the descent table.

[Schedule Manager](../../../../docs/DEMO_GUIDE.md) describes the mission context. Its UTC sample times are independent of the demo’s elapsed time. Terrain clearance, landing safety and radio availability require separate analysis.
