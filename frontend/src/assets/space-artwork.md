# Decorative Home scene artwork

`orbital-earth.jpg` is NASA's Apollo 17 Blue Marble photograph (December 7, 1972), downloaded as the 1024 × 1024 print image.

- Official source and credits: https://svs.gsfc.nasa.gov/30613/
- Download: https://svs.gsfc.nasa.gov/vis/a030000/a030600/a030613/blue_marble_apollo_17_19721207_print.jpg
- Credit: Earth Science and Remote Sensing Unit, NASA Johnson Space Center.
- Local file: 265,324 bytes. Served as a bundled asset; no remote image request at runtime.
- Presentation: circular CSS crop, decorative shading and glow. This historical photograph does not depict the selected mission epoch, live weather, or computed observer geometry.

The seeded starfield, dust lanes, Sun glow, visual sizes and celestial positions are artistic. Stars are not an astronomical catalogue. No scientific calculations or provider values are derived from these assets.
